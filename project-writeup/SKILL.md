# Project write-up

## Inputs
1. The project itself: the page's text, the slide's bullets, or the file.
2. The platform's description prompt (the questions it asks).
3. Anything the author tells you about how it was made.

## Steps
1. List the facts you can see in the project: features, numbers, names, sources.
2. Write a title that names the thing and what it does, under 60 characters.
3. Answer each question in the prompt, in order, in plain sentences.
4. Check every sentence against step 1. Delete any claim you cannot point to
   in the project or in what the author told you.
5. If the project was made differently from what the platform expected (a
   different tool, a mockup instead of a live app), say so in one sentence.
6. Count characters. Stay under 500.

## Rules
- Never invent results, users, test outcomes or personal anecdotes.
- Label plans as plans ("next I'd...") and assumptions as assumptions.
- Prefer concrete details from the project over adjectives.
- No hype words: revolutionary, game-changing, seamless.
