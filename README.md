# Skills Studio projects

Small single-file web apps built for Handshake AI Skills Studio missions. Live at https://eswar1207.github.io/skills-studio/

| Page | What it is |
|---|---|
| index.html | Personal site |
| resume.html | Visual resume with a Q&A "ambassador" |
| study.html | Flashcard + quiz study app |
| game.html | Drop Four, two-player pass-and-play |
| focus.html | FocusBlocks productivity timer |
| tracker.html | Job search command center (`?mode=crm` for the sales CRM) |
| dashboard.html | AI adoption vs trust dashboard |
| decide.html | Laptop now-or-later decision model |
| pipeline.html | RecipeScaler, an app that shows its work |
| splitmate.html / plantpal.html | Clickable app prototypes |
| gift.html | Exam Season Jar gift app |
| gallery.html | Generative landscape gallery |
| landing.html / event.html | Campaign landing page and event page |
| teamhq.html | Team home page |
